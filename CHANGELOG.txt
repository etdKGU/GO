#Учёт личных трат

Веб-приложение на Go для учёта расходов.

#Что внутри

- cmd/web: запуск сервера
- internal/handlers: обработчики запросов
- internal/models: структуры данных
- internal/repository: работа с базой SQLite
- migrations: SQL-скрипт создания таблицы
- web/templates: HTML-шаблоны
- web/static: CSS

#ИЗМЕНЕНИЯ ПОСЛЕ ВТОРОГО ЭТАПА

- Добавлены проверки на сервере: сумма больше нуля, описание не пустое, дата корректная
- Добавлены проверки в формах (required, min, maxlength) и свои сообщения об ошибках
- Подключён CSS из web/static, меню в шапке выровнено в ряд

#ТРЕТИЙ ЭТАП
 
- Подключил SQLite (драйвер modernc.org/sqlite)
- Создал таблицу expenses (id, amount, description, date) через SQL-файл migrations/create_table.sql, таблица создаётся при старте сервера
- Написал репозиторий (internal/repository) с методами Create, GetAll, GetByID, Update, Delete
- Весь SQL находится только в репозитории, в обработчиках его нет
- Все запросы написаны с плейсхолдером ? вместо склейки строк (защита от SQL-инъекций)
- Добавил удаление траты: кнопка с подтверждением, POST-запрос
- Добавил редактирование траты: форма с заполненными полями и сохранение через Update
- Данные сохраняются в файл expenses.db и не пропадают после перезапуска сервера
